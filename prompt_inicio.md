# Prompt de inicio — pegar en la primera sesión de Claude Code

---

Vas a desarrollar **Grietas: Entre tú y el otro lado**, un juego 2D web completo.

Antes de hacer cualquier cosa, lee estos archivos en este orden:

1. `docs/AGENTS.md` — tus directivas de trabajo
2. `docs/arquitectura_tecnica.md` — stack, estructura de archivos, patrones
3. `docs/grietas_lore.md` — el mundo, personajes y narrativa
4. `docs/level_design.md` — zonas, mapas y posiciones
5. `docs/dialogue_trees.md` — todos los diálogos
6. `docs/game_states.md` — flags y estado del mundo

Cuando termines de leer los 6 documentos, responde con:
- Un resumen de 5 líneas de lo que vas a construir
- Confirmación de que entendiste el stack (sin frameworks de juego externos)
- La primera tarea de la Fase 1 que vas a ejecutar

No escribas código todavía. Primero confirma que leíste y entendiste todo.
